# Tickets React Starter

Proyecto base con React 18, TypeScript, Vite y React Router 6.

## Arranque

```bash
npm install
npm run dev
```

Abre la ruta `/teams/demo/tickets?offset=0`.

## API

Vite reenvía `/api/*` a `http://localhost:3001`. Para cargar tickets necesitas un backend compatible con la ruta usada por `TicketsPage`.

## Nota sobre el código inicial

El contenido de `src/pages/TicketsPage.tsx` conserva literalmente el fragmento proporcionado, sin correcciones ni refactorizaciones. Los componentes auxiliares y la configuración se incluyen para completar la estructura del proyecto.
